# Тележка «Пролёт»

3D-модель тележки, которая едет по прямому проводу и проходит изоляторы на телескопических роликах. Между изоляторами провод провисает, тележка этот провис не объезжает снизу.

## Открыть модель

[https://wondolmer.github.io/prolet-3d/](https://wondolmer.github.io/prolet-3d/)

Нужен обычный браузер. Модель крутится сама. Мышью можно поворачивать обзор, колёсиком — приближать.

- **Пауза** — остановить и снова запустить ход.
- **На проводе** — тележка на линии.
- **Детали по отдельности** — колесо, батарея, захват и гирлянда рядом, без провода.

Отдельно ничего ставить не нужно: библиотека трёхмерной графики лежит в папке `vendor`.
